The transport boundary

Three methods.
Your packet carrier.

The Go core depends on WGC v0.2.0. Its transport interface exchanges WireGuard messages with remote endpoints.

Only standard UDP ships. Your private authentication, relaying, framing, or obfuscation belongs in a wrapper compiled into your Go core.

An example from the architecture document. Replace the key placeholders and use addresses allowed by your remote WireGuard server.

Required inputs
version, private_key, addresses, and peers. Endpoints and resolvers must be numeric and unzoned.
Platform owns the routes
NetworkExtension installs network settings. The core adds each peer’s outer endpoint host route to the exclusions.
Credentials stay on device
Configuration goes into a device-only Keychain item in your shared access group. Preferences hold a profile reference, not private keys or full configuration.

sing-box, with a defined scope.

The default policy sends TUN TCP/UDP and DNS through the selected peer. Raw ICMP forwarding is outside the userspace outbound’s stated scope.

Containing app
Own the UI, accounts, API integrations, and policy. Use the Flutter plugin to manage your native profile and read status.
PacketTunnel target
Run Swift and Go, without a Flutter engine. Link your chosen WGCCore.xcframework; set the NetworkExtension and matching shared Keychain entitlements.
Custom Go core
Compile private transport factories and wrappers into this binary. A transport name in JSON selects code already registered in your build.
